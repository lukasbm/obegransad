Status

- httpd_resp_set_hdr(char* field, char* value) : Sets a header
- httpd_resp_set_status(char* status) : Sets the status code
- httpd_resp_set_type(char* type) : Sets the content type
- httpd_resp_send(const char *buf, ssize_t buf_len) : Sends a response
- httpd_resp_send_chunk(const char *buf, ssize_t buf_len) : Sends a chunk of data
- httpd_resp_send_err(httpd_err_code_t status, char* message) : Sends an error response
- httpd_resp_send_custom_err(const char *status, const char *msg) : 
- httpd_resp_sendstr(const char *str) : Sends a string (more convenient than regular send if it is a null terminated string.)
There are also helper functions like httpd_resp_send_xxx
